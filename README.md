# Transit Capacity Multiplier

Transit Capacity Multiplier adjusts how many passengers transit vehicles can carry by multiplying each vehicle type’s base capacity.

## What it does

- Change capacity for:
  - Bus
  - Taxi
  - Subway
  - Tram
  - Train
- Multiply default capacity by a configurable factor per type.
- Increase or reduce capacities for balancing transit flow.

## Use case

- Useful for gameplay balancing of transit congestion and comfort without changing schedules.
